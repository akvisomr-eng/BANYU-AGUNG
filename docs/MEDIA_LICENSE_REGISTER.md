# Register Lisensi Media — BANYU AGUNG

Tanggal pemeriksaan awal: 16 November 2026.

## Prinsip penggunaan

- Hanya gunakan media yang halaman sumbernya secara eksplisit menyatakan lisensi gratis untuk penggunaan komersial atau lisensi setara yang telah diperiksa.
- Simpan URL halaman aset, nama kreator, tanggal unduh, jenis lisensi, dan salinan/screenshot ketentuan yang berlaku pada saat pengunduhan.
- Jangan menganggap lisensi hak cipta otomatis mencakup hak merek, model release, property release, privasi, atau hak atas objek yang tampak dalam media.
- Jangan menggambarkan foto/video stok sebagai sumber air, pabrik, karyawan, produk, sertifikat, atau fasilitas BANYU AGUNG yang sebenarnya.
- Jangan menggunakan media stok sebagai logo atau merek dagang. Jangan menjual kembali file stok dalam bentuk berdiri sendiri.
- Sebelum media diunduh dan di-host sendiri, tinjau kembali halaman lisensi dan catat bukti lisensinya. Link halaman sumber disimpan di bawah.
